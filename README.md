# Discord AI Moderator

Discord-модератор на Python с мультимодальной проверкой текста и изображений через OpenAI `omni-moderation-latest`.

## Возможности

- Проверка текста сообщений.
- Проверка изображений во вложениях.
- Риск 0–10 на основе максимальной category score.
- Порог по умолчанию: 8.0.
- TEST MODE: бот не удаляет, не мутит и не уведомляет модераторов; вместо этого ставит реакцию с округлённым баллом.
- LIVE MODE: подозрительные сообщения передаются модератору с кнопками `Оставить`, `Удалить`, `Мут`.
- Логи в SQLite и отдельный Discord-канал.
- `/admin` для вызова администрации.
- Игнорирование отдельных каналов и ролей.

## Установка

Требуется Python 3.11+.

```bash
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows
# .venv\\Scripts\\activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `DISCORD_TOKEN` и `OPENAI_API_KEY`.

Для Discord-приложения включите `Message Content Intent` и `Server Members Intent` в Developer Portal. Боту нужны как минимум права на просмотр каналов, чтение истории, добавление реакций и отправку сообщений; для кнопки мута также требуется `Moderate Members`, а для удаления — `Manage Messages`.

## Запуск

```bash
python bot.py
```

## Тестовый режим

В `.env`:

```env
TEST_MODE=true
```

Или после запуска:

```text
/testmode enabled:true
```

В TEST MODE бот только анализирует сообщения и ставит одну реакцию: `0`–`9` или `🔟`, соответствующую округлённому риску 0–10. Никаких модераторских уведомлений, DM, удаления или мута в этом режиме нет.

## Боевой режим

```env
TEST_MODE=false
MODERATION_THRESHOLD=8.0
MOD_ALERT_CHANNEL_ID=ID_КАНАЛА_МОДЕРАЦИИ
MOD_LOG_CHANNEL_ID=ID_КАНАЛА_ЛОГОВ
ADMIN_CHANNEL_ID=ID_КАНАЛА_АДМИНИСТРАЦИИ
TIMEOUT_MINUTES=10
```

При результате `>= 8.0` создаётся карточка для модераторов. AI не принимает окончательное решение: действие выполняет человек через кнопки.

## Важное замечание по баллу

Moderation API возвращает отдельные category scores, а не универсальный «балл нарушения». Этот проект переводит максимальный category score в шкалу 0–10. Поэтому `8.0` означает, что хотя бы одна категория получила score `0.80` или выше.

## Команды

- `/testmode enabled:true|false` — TEST/LIVE режим.
- `/modstatus` — состояние модерации.
- `/admin reason:...` — вызвать администратора.

## Безопасность

Не публикуйте `.env`, Discord token или OpenAI API key. Файл базы `moderation.db` также может содержать идентификаторы пользователей и сообщения о результатах модерации; храните его с учётом правил приватности вашего сервера.
